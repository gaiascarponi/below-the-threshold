# Below the Threshold

Code and results for the MSc thesis

> **Below the threshold: the transcriptomic trace of acute trauma, its transfer to chronic poverty and the burden of psychosocial adversity on population health**
>
> Gaia Scarponi, MSc in Artificial Intelligence and Robotics, Sapienza University of Rome, Department of Computer, Control and Management Engineering "Antonio Ruberti", academic year 2025/2026.
> Advisor: Prof. Giulia Fiscon. Co-advisor: Dr. Federica D'Annunzio.

## Overview

The thesis compares four forms of psychosocial adversity, each represented by one public blood transcriptomic dataset analyzed with the same pipeline, and estimates the burden of each on population health.

| Axis | Adversity | GEO | Tissue, platform |
|---|---|---|---|
| A | Acute mass trauma (World Trade Center responders, PTSD) | GSE97356 | whole blood, RNA-seq |
| B | War and combat trauma (US Marines, PTSD) | GSE64813 | leukocytes, RNA-seq |
| C | Chronic poverty (HANDLS, below vs above 125% of the poverty line) | GSE221766 | PBMCs, RNA-seq |
| D | Early-life adversity | GSE70603 | CD14+ monocytes, microarray |

Two readings of the same four exposures are produced:

- **Molecular reading**  
    - Level 1: preprocessing, differential expression (DESeq2, limma) and functional enrichment (ORA, GSEA) on each axis. 
    - Level 2 (Axis A only): switch genes (SWIMmeR), miRNA enrichment (MIENTURNET) and protein interaction network (STRING). 
    - Level 3: transfer of the Axis A signature to the gene rankings of Axes B, C and D (fgsea), with sensitivity, leading-edge, cell composition and specificity analyses.
- **Cost reading**  \
    Adisability-adjusted life year (DALY) model based on published epidemiological inputs and GBD 2023, with Monte Carlo uncertainty, for the United States and Italy. It does not use the expression data.

## Repository structure

```
00_config.R, 00_functions.R, 00_source.R   shared configuration (thresholds, datasets) and functions
01_run.R                                   runs the whole pipeline in order
A_mass_trauma/   B_war_trauma/   C_poverty_ses/   D_early_adversity/
    00_preprocessing.R, 01_DEG.R, 02_enrichment.R
    01_source/        input data from GEO (not included, see below)
    02_processed/     intermediate files
    03_results/       results: data/ (DEG_full_results.rds), tables/, plots/
A_mass_trauma/04_network/                  Level 2: SWIMmeR, MIENTURNET and STRING results
Transferability/                           Level 3 scripts (00 - 05), data/ and results/
Transferability/Dictionary/                gene identifier and gene set references (HGNC, NCBI Gene, MSigDB, MCP-counter)
DALY/                                      social cost model: scripts 00 - 06, results/, figures/
SWIMmeR/project/                           SWIMmeR input folders (sample group lists only)
sessionInfo_R.txt                          R and package versions
```

All results used in the thesis are included (tables, figures and `.rds` objects). In particular, `*/03_results/data/DEG_full_results.rds` contains the complete differential expression results of each axis.

## Data not included

The following files are not redistributed and must be downloaded to reproduce the analyses:

- **GEO datasets.** Download the series matrix and the supplementary count files of GSE97356, GSE64813, GSE221766 and GSE70603 from the [Gene Expression Omnibus](https://www.ncbi.nlm.nih.gov/geo/) into the corresponding `*/01_source/<GSE id>/` folder. For Axis D, the platform annotation (GPL17077) is downloaded by the preprocessing script.
- **GBD 2023.** The DALY inputs are downloaded from the [GBD Results Tool](https://vizhub.healthdata.org/gbd-results/) into the folders of `DALY/data/source/`, whose names indicate the cause, risk and location required.
- **SWIMmeR input matrices.** The normalized expression matrices used by SWIMmeR (`SWIMmeR/project/*/dataset/matrix/`) are generated by the preprocessing scripts and are not included because of their size.

## Reproducing the analyses

The analyses were run in R 4.6.1; package versions are listed in `sessionInfo_R.txt`. Open `Project.Rproj` so that all paths are relative to the repository root.

`01_run.R` runs the whole pipeline in order (Levels 1 and 3 and the cost model). The steps can also be run separately:

1. **Level 1.** For each axis, `00_preprocessing.R`, `01_DEG.R` and `02_enrichment.R`.
2. **Level 2 (Axis A).** SWIMmeR is an external tool (Paci et al., 2017) and its source code is not included. The thesis run used seed 18 and k = 3; parameters and outputs are documented in `A_mass_trauma/04_network/swimmer/`. MIENTURNET and STRING were used through their web interfaces; inputs and results are in `A_mass_trauma/04_network/`.
3. **Level 3.** Run the scripts in `Transferability/` in numerical order, from `00_harmonize_gene_ids.R` to `05_specificity.R`; `plot_hallmark_heatmap.R` draws the cross-axis Hallmark heatmap after `02_functional_gsea_all_axes.R`.
4. **Cost model.** Run the scripts in `DALY/` in numerical order, from `01_axisA_PTSD_DALY.R` to `06_italy_comparison.R` (each loads `00_daly_functions.R`).
